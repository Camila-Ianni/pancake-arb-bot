# Instrucciones para completar el archivo .env

Este archivo es esencial para la correcta ejecución del bot de arbitraje de Polymarket. Asegúrate de seguir los pasos a continuación para completar cada campo requerido.

## 1. METAMASK_KEY
 - **Descripción**: Esta es la clave privada de tu cuenta de MetaMask. 
 - **Cómo obtener**: Abre tu extensión de MetaMask, selecciona la cuenta deseada y en el menú de configuración, ve a "Seguridad y privacidad". Busca "Exportar clave privada". **Recuerda nunca compartir esto con nadie.**

## 2. INFURA_URL
 - **Descripción**: Serás utilizando el servicio Infura para conectarte a la red Ethereum.  
 - **Cómo obtener**: Crea una cuenta en [Infura](https://infura.io/), selecciona un proyecto y copia el URL del punto final que configurarás en tu archivo .env.

## 3. POLYMARKET_API_KEY
 - **Descripción**: Necesitarás una clave para acceder a la API de Polymarket. 
 - **Cómo obtener**: Regístrate en [Polymarket](https://polymarket.com/) y busca en la sección de desarrolladores para generar una nueva clave API.

## 4. OTHER_VALUE
 - **Descripción**: Aquí puedes incluir otros valores que tu bot necesite, como tasas de gas o ajustes de rendimiento.  
 - **Cómo obtener**: Esto dependerá de tu configuración personal. Si utilizas ajustes estándar, esto puede ser opcional.

## Notas Importantes
- Asegúrate de no compartir tu archivo .env en lugares públicos para evitar comprometer la seguridad de tu cuenta.
- Revisa siempre que los valores sean correctos antes de iniciar el bot.

Si tienes dificultades, consulta la documentación oficial de cada servicio mencionado.
