# Polymarket Multi-Asset Sniper

Bot HFT de arbitraje para mercados de 5 minutos en Polymarket con soporte multi-activo (BTC, ETH, SOL, BNB), stake dinámico y ejecución concurrente.

La guía completa de instalación y uso está en:

- `docs/README.md`

## Inicio rápido

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```
